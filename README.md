# 🌮 The Little Taco Shop

A semantic, responsive, multi-page static website for a taco shop.

## 🚀 Live Demo
[View Live Site](https://sathwikachodavarapu.github.io/Little-Taco-Shop/)

## 📖 Overview
This project was built to practice and demonstrate modern HTML5 semantic structure, accessible navigation, document outline hierarchy, and form handling.

### Key Highlights
- **Semantic Structure:** Implemented `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<figure>`, and `<footer>` tags.
- **Multi-Page Routing:** Seamless navigation between `index.html`, `hours.html`, and `contact.html`.
- **Accessible Pricing Table:** Menu structured using `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, with `rowspan`, `colspan`, and `scope` attributes.
- **Interactive Elements:** Native HTML5 `<details>` / `<summary>` trivia widget and a complete contact form with input validation.
